This is a surprise Christmas themed little game that includes a message text, a minigame and also a cute background themed music with UX.
NOTE:
HOW TO OPEN IT?
1. Requires a Java Enviroment support: https://www.oracle.com/java/technologies/downloads/#jdk26-windows
verify if java is installed java --version
2. Open Command Prompt and change the directory location to where the file is: cd file_adress
3. Run java -jar Christmas.jar
